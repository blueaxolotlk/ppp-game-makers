How it works
  1. Add a single HTML file, a folder, several files, or a ZIP
  2. Click Start Processing — files are analyzed, split, and image-compressed
  3. Split files become .p001, .p002… parts plus a .split.json manifest
  4. Split HTML pages get a generated loader index.html that reassembles them
  5. Download one ZIP, extract it, and commit the contents to GitHub
